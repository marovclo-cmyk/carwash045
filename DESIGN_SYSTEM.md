> **Статус:** v1 «Glass/Orb» полностью внедрён (Этапы 1–6, см. ниже и
> `CHANGELOG.md`). Сейчас идёт **новый раунд** миграции на v2-палитру
> из `carwash-showcase-concept.html`. Прогресс v2 — в разделе

> тем же правилам: после этапа — правка проекта → обновление .md →

Источник: `main-page-concept.html`, присланный пользователем как эталон
нового дизайна. Цель миграции — перевести весь сайт (`webapp/static/*.html`)
и Mini App (`webapp/static/index.html`) на этот визуальный язык, не ломая
существующую функциональность и backend.

Работа ведётся ПОЭТАПНО (см. чек-лист в конце файла). Этот файл — общий
источник правды по токенам и переиспользуемым компонентам; страничные
`.md`-файлы (`NEW_STRUCTURE.md`, `MINIAPP_AUDIT.md`) фиксируют прогресс по
конкретным экранам.

## 1. Где живут токены

- **Сайт**: `webapp/static/site-theme.css` — подключается один раз через
  `site-common.js` на все страницы сайта (кроме `site-login.html`, где
  подключён напрямую `<link>`).
- **Mini App**: `webapp/static/index.html` — свой инлайн `<style>` (SPA не
  грузит `site-theme.css` отдельно), поэтому те же токены и классы
  продублированы внутри файла. При изменении палитры/компонентов — менять
  синхронно в обоих местах.

## 2. Палитра (токены)

| Переменная | Значение (тёмная тема) | Назначение |
|---|---|---|
| `--bg` | `#08080B` | фон приложения/сайта |
| `--surface-0..3` | `#0F1116 → #262832` | непрозрачные поверхности (сайдбар, инпуты) — используются там, где glass-эффект не нужен |
| `--text` / `--text-secondary` / `--text-muted` | `#F5F6FA` / `#9096A3` / `#5E6270` | текст (старые имена, используются в уже написанных экранах) |
| `--text-dim` / `--text-faint` | `rgba(245,246,250,.56)` / `.34` | текст новых glass-компонентов (из концепта) |
| `--accent` / `--accent-b` | `#6A8BFF` / `#A24BFF` | основной градиент (кнопки, активные состояния, hero) |
| `--good` / `--green` | `#34D399` | успех/оплачено |
| `--orange` | `#FFB648` | предупреждение/в работе |
| `--red` | `#FF6B8B` | ошибка/удаление |
| `--glow-a/b/c` | `#3B6BFF` / `#A24BFF` / `#FF4FA3` | цвета фоновых «орбов» и hero-градиента |
| `--glass` / `--glass-hover` / `--glass-border` | `rgba(255,255,255,.055/.09/.09)` | фон/бордер стеклянных карточек |

Радиусы: `--radius-sm:12px`, `--radius-md:16px`, `--radius-lg:22px`,
`--radius-xl:30px`. Блюр: `--blur-glass:20px`, `--blur-nav:28px`.

Светлая тема (`html[data-theme="light"]`) использует те же имена
переменных с адаптированными значениями (glass — тёмный полупрозрачный на
светлом фоне, а не белый).

Старые переменные (`--surface-*`, `--accent-tint`, `--purple-tint` и т.п.)
**сохранены** — их использует весь уже написанный HTML/JS. Новые токены
добавлены рядом, ничего не переименовано и не удалено, чтобы не сломать
страницы до того, как до них дойдёт очередь по плану.

## 3. Переиспользуемые компоненты (одинаковые классы на сайте и в аппе)

- **`.orb-bg` + `.orb.orb-a/.orb-b/.orb-c`** — фиксированный слой из 3
  размытых цветных пятен (`filter:blur(90px)`), плавно двигающихся
  (`@keyframes orb-float-1/2`). Добавляется один раз в разметку страницы,
  `pointer-events:none`, не мешает контенту.
- **`.glass-card`** — базовая полупрозрачная карточка с блюром фона
  (`backdrop-filter`). Строительный блок для списков, статов, секций.
- **`.hero-card`** — крупная карточка с анимированным цветным градиентом
  (`@keyframes hero-shift`) для главных сумм/итогов (выручка за смену,
  баланс).
- **`.pill.ok` / `.pill.wip`** — статус-бейджи (оплачено / в работе).
- **`.action-tile`** + `.sq.b1..b4` — квадратные плитки быстрых действий
  с цветными градиентными иконками.
- **`.glass-navbar`** — плавающий полупрозрачный нижний навбар (мобильный).

### Этап 5 — детали (Сайт: страницы по одной)

Важная находка: каждая из 10 страниц сайта хранит собственную инлайн-копию
общего каркаса (`:root`, `.sidebar`, `.panel`, `.stat-card`, `.btn` и т.д.) —
устаревшее легаси ещё с ранних версий проекта. Но `site-common.js`
подключает `site-theme.css` через `document.head.appendChild(...)`, что
физически помещает этот `<link>` **после** инлайн-`<style>` каждой
страницы. При равной специфичности побеждает последнее по порядку
правило — то есть `site-theme.css` **уже перекрывал** все инлайн-копии на
всех 10 страницах начиная с Этапа 4, просто это не было явно
задокументировано. Проверено сравнением (`diff`) стилей всех страниц:
структура идентична, отличаются только значения (палитра, отступы),
которые не участвуют в рендере, потому что переопределены.

Из-за этого страницы сайта уже выглядели в стиле «Glass/Orb» сразу после
Этапа 4. Этап 5 добавил точечные глобальные переопределения в
`site-theme.css` (используют `!important` там, где нужно перебить
инлайн-правило с точно такой же специфичностью и структурой селектора) —
они автоматически применились сразу ко всем страницам, которые содержат
эти компоненты:

- **`.pay-tag`** (способ оплаты — Dashboard/Касса/Финансы/История):
  прямоугольный бейдж → пилюля (`border-radius:100px`), как `.pill` в
  дизайн-концепте.
- **`table.data`** (таблицы операций — Dashboard/Финансы/История/Отчёты):
  hover-строка — `--glass-hover` вместо сплошного `--surface-2`; границы
  ячеек — `--glass-border`.
- **`.tag`** (статусы — Мойщики/Филиалы): пилюля вместо прямоугольника.
- **`.tabs`/`.tab`** (переключатель периода — Отчёты): glass-таблетка,
  активный сегмент — акцентный градиент (как `.segmented`/`.seg` в
  mini-app).
- **`.branch-card`** (карточки филиала — Филиалы/Отчёты): glass + блюр.
- Добавлен токен `--accent-gradient` в `site-theme.css` (уже был в
  `index.html`) для переиспользования в `.tab.active` и будущих правках.

Не тронуто в этом этапе намеренно: мелкие внутренние элементы форм
(`.svc-item`, `.csf-row`, `.split-row`, `.field`, `.list-row` и т.д.) —
это строки/чипы **внутри** уже стеклянных `.panel`/`.card`, их сплошной
слегка затемнённый фон обеспечивает читаемость поверх блюра (аналог
`.action-tile .sq` в концепте — сплошной элемент поверх стекла). Полная
инвентаризация всех 10 инлайн-`<style>`-блоков как технический долг
(дублирование, устаревшие переменные) вынесена в раздел «Известные
ограничения» ниже — переписывание не требуется для итогового вида, но
может быть сделано отдельно для чистоты кода.

## v2 Cloud Showcase (новый раунд редизайна)

Источник: `carwash-showcase-concept.html`, присланный пользователем как
эталон нового визуального языка (плюс 2 референса-скриншота — Forma
Studio и карточка объявления недвижимости — как настроение "тёмное
фото + белые стеклянные пилюли/карточки поверх"). В отличие от
`main-page-concept.html` (эталон v1), это не макет экрана приложения,
а витринная карточка-промо — из неё извлекается **язык компонентов и
токены**, а не буквальная разметка: тёмно-бирюзовый фон, стеклянные
пилюли-навигация, крупный заголовок шрифтом Fredoka, контрастные
непрозрачные тёмные карточки со статистикой (`.stat-card`), белые
"стеклянные" карточки-описания (`.note-card`, `.listing`), круглый
акцентный бейдж, цветные свотчи тарифов.

### Стадия 1 — токены и шрифты (готово)

Новые переменные добавлены **рядом** со старыми v1-токенами (не
заменяют их) — в `webapp/static/site-theme.css` (`:root`) и
синхронно в инлайн `<style>` `webapp/static/index.html`, чтобы на
следующих этапах точечно переводить экраны на v2, не ломая уже
готовый v1-вид остальных.

| Переменная | Значение | Назначение |
|---|---|---|
| `--v2-outer` / `--v2-outer-2` | `#0B3E47` / `#052226` | тёмно-бирюзовый фон-подложка (радиальный градиент) |
| `--v2-ink` | `#0B1F24` | текст/фон тёмных solid-карточек |
| `--v2-glass` / `--v2-glass-strong` / `--v2-glass-border` | `rgba(255,255,255,.15/.94/.32)` | стеклянные пилюли (полупрозрачные) и почти-непрозрачные белые карточки |
| `--v2-accent` | `#4E9BFF` | основной акцент (было `--accent` в v1 — не путать, разные палитры) |
| `--v2-econ` / `--v2-prem` | `#34D399` / `#B98CFF` | цвета тарифов "Эконом"/"Премиум" (свотчи) |
| `--v2-badge` | `#6C4DFF` | круглый акцентный бейдж |
| `--v2-gold` | `#FFC24B` | рейтинг/звёзды |
| `--v2-card-ink` / `--v2-card-soft` | `#122428` / `#5C6E72` | текст на белых стеклянных карточках (заголовок/подпись) |
| `--v2-radius-xl/lg/md/sm` | `40/26/20/12px` | радиусы v2-компонентов (крупнее, чем в v1) |
| `--font-display` | `'Fredoka'` | крупные заголовки |
| `--font-body` | `'Inter'` | основной текст (уже использовался как системный шрифт — теперь явный) |
| `--font-mono` | `'IBM Plex Mono'` | числа/статистика (`.v2-mono`) |

Шрифты подключены через `@import` в начале `site-theme.css` (грузится
на всех страницах сайта и в Mini App), а не отдельным `<link>` в
каждом файле — одна точка правки.

Новые базовые классы (готовы к использованию в следующих этапах,
пока нигде не применены на реальных экранах):

- `.v2-pill` / `.v2-pill.strong` — стеклянная пилюля-навигация (прозрачная / почти-белая)
- `.v2-card-solid` — тёмная непрозрачная карточка (как `.stat-card` в концепте)
- `.v2-card-glass` (+ `.v2-soft` для второстепенного текста) — белая полупрозрачная карточка (как `.note-card`/`.listing`)
- `.v2-badge-circle` — круглый акцентный бейдж
- `.v2-swatch` / `.v2-swatch.on` — цветной свотч тарифа
- `.v2-display` / `.v2-mono` — шрифтовые утилиты

**Затронутые файлы:** `webapp/static/site-theme.css`,
`webapp/static/index.html` (только `:root` и новые utility-классы —
существующая разметка экранов ещё не тронута).

**Следующий этап (2):** переприменить эти токены на конкретный
экран/страницу — какую именно начать первой, будет уточнено с
пользователем перед стартом.

### Стадия 2 — экран Dashboard (сайт) (готово)

Переведён на v2 первый реальный экран: `webapp/static/dashboard.html`.
Выбор пал на Dashboard по решению пользователя.

**Подход:** все переопределения добавлены **только внутри самой
страницы** — новый блок `<style id="v2-dashboard-overrides">` вставлен
сразу после `<link href="site-theme.css">` и полностью скоуплен
классом `.v2-page` (добавлен на `<body>`). Общий `site-theme.css` не
менялся (кроме токенов из Стадии 1) — остальные 9 страниц сайта
по-прежнему выглядят как v1 «Glass/Orb», ничего не сломано.

Что изменилось на Dashboard:

- **Фон** — вместо тёмного `--bg` и плавающих орбов (`#cw-orb-bg`
  скрыт через `display:none` только на этой странице) — радиальный
  тёмно-бирюзовый градиент `--v2-outer`/`--v2-outer-2`, как в
  концепте.
- **Сайдбар** — стал плавающей стеклянной панелью (`--v2-glass` +
  блюр 20px, скруглён только с правой стороны, с отступом от края
  экрана), активный пункт меню — белая пилюля вместо подсветки
  цветом.
- **Заголовок страницы** — шрифт Fredoka (`--font-display`).
- **Hero-карточка выручки** (`.hero-glass.dash-hero`) — превращена в
  тёмную непрозрачную ink-карточку (как `.stat-card` в концепте),
  число выручки — моно-шрифтом IBM Plex Mono.
- **Стат-карточки и панели** (таблица машин, зарплаты сотрудников) —
  стали белыми "стеклянными" карточками (`--v2-glass-strong`),
  текст перекрашен в тёмный (`--v2-card-ink`/`--v2-card-soft`), т.к.
  они теперь светлые, а не тёмные.
- **Пилюли способа оплаты** — перекрашены в v2-палитру (эконом-зелёный
  для нал, синий для карты, золотой для безнала).
- **Кнопки** — стали пилюлями (`border-radius:100px`), primary —
  залита `--v2-accent`.

**Затронутые файлы:** `webapp/static/dashboard.html` (добавлен
`class="v2-page"` на `<body>` + новый `<style>` блок с
переопределениями; JS-логика и структура разметки не менялись).

**Следующий этап (3):** следующий экран/страница — уточняется с
пользователем.

### Стадия 3 — Касса/Машины/Финансы/История/Отчёты (готово)

Пользователь разрешил дальше выбирать порядок страниц самостоятельно и
довести редизайн до конца без дополнительных согласований на каждом
шаге.

**Рефакторинг перед продолжением:** переопределения `.v2-page` из
Стадии 2 были **вынесены из `dashboard.html` в `site-theme.css`**
(общий файл, уже загружаемый на всех страницах) и обобщены под общие
имена классов, которые использует не только Dashboard, но и
остальные страницы (`.branch-card`, `.tag`, `.list-row`, `.tabs/.tab`,
`.modal`, `.entry` и т.д.). Так новые страницы не требуют копирования
одного и того же CSS-блока — достаточно добавить `class="v2-page"` на
`<body>`. Сам `dashboard.html` теперь тоже просто использует этот
общий блок — визуально ничего не изменилось.

Применено `class="v2-page"` к: `cash.html`, `cars.html`,
`finance.html`, `history.html`, `reports.html`. Разметка и JS этих
страниц не менялись — только фон, сайдбар, панели/карточки, таблицы,
пилюли и кнопки перекрашены через уже существующие общие правила
(плюс добавлены точечные правила для специфичных для этих страниц
классов: `.list-row`/`.list-amount` (касса/финансы), `.accent-green/
red/purple` (финансы/лояльность), `.tabs/.tab` и `.branch-card`
(отчёты), `.entry-*` (история)).

**Затронутые файлы:** `webapp/static/site-theme.css` (общий блок
`.v2-page`, дополнен новыми правилами), `webapp/static/dashboard.html`
(локальный блок стилей удалён, оставлен только класс), `cash.html`,
`cars.html`, `finance.html`, `history.html`, `reports.html` (добавлен
`class="v2-page"` на `<body>`).

### Стадия 5 — Mini App (готово)

Тот же приём, что и на сайте: класс `class="v2-page"` добавлен на
`<body>` `webapp/static/index.html`, а под него — один блок
переопределений в конце существующего `<style>` (Mini App не грузит
`site-theme.css` отдельным файлом, поэтому CSS живёт инлайн, как и
было в v1). Переопределяются общие переиспользуемые классы экранов —
значит эффект сразу на всех вью (Главная/Касса/Машины/Финансы/
Отчёты/Сотрудники/Настройки/История), без правки каждой
`render*`-функции:

- Фон — тёмно-бирюзовый радиальный градиент вместо орбов (`.orb-bg`
  скрыт через `.v2-page .orb-bg{display:none}`).
- `.topbar-title` — Fredoka; `.home-branch-chip`/`.bell-btn` — стеклянные пилюли.
- `.home-hero` (карточка выручки) — тёмная непрозрачная ink-карточка, сумма — моно-шрифтом.
- `.home-segmented`/`.segmented` — светлый активный сегмент вместо градиента.
- `.card`, `.glass-card`, `.op-list`, `.home-stat-box`, `.rstat-box`,
  `.worker-card`, `.branch-card`, `.total-card` — единообразно
  переведены в белые "стеклянные" карточки с тёмным текстом.
- `.action-tile`, `.tile` — тоже светлые карточки (были тёмными в v1).
- `.pill.ok`/`.pill.wip`, `.tag` — перекрашены в v2-палитру.
- `.glass-navbar`/`.tabbar` (нижняя навигация) — светлее и прозрачнее.
- `.btn` — пилюли вместо прямоугольных кнопок.
- `.sheet` (нижний лист) — тёмная ink-подложка.

**Важный нюанс:** при первой попытке добавить `class="v2-page"` на
`<body>` случайно была задета соседняя строка с оборачивающим
`<div class="orb-bg">` (авто-замена зацепила её целиком) — div остался
без открывающего тега при сохранённых closing-тегах. Поймано сразу же
проверкой баланса `<div>`/`</div>` (538/538 до правки не сходилось),
исправлено восстановлением обёртки; после фикса баланс тегов и скобок
подтверждён, оба инлайн-`<script>` синтаксически корректны
(`node -e "new Function(...)"` без ошибок).

**Затронутые файлы:** `webapp/static/index.html` (класс на `<body>` +
новый CSS-блок в конце `<style>`; JS и структура рендер-функций не
менялись).

**Следующий этап (6, финальный):** полная сборка — все проверки,
общий CHANGELOG, список правок и объяснений, единый deploy-ready ZIP
для Railway.
