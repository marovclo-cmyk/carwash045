# CarWash Cloud × Plata — прогресс редизайна

Дизайн-референс: бренд-гайд Plata / Banco Plata (design.platacard.mx).
Цвет: Plata Orange `#FF5000` + чёрный/белый. Шрифт: замена закрытого
Rothorn на Clash Display + General Sans (Fontshare, свободные).
Логотип/товарный знак Plata не копируется — только визуальный язык
(цвет, форма, типографика, сетка).

## Структура
- `css/theme-plata.css` — единая тема: токены + все переиспользуемые
  компоненты (сайдбар, панели, таблицы, карточки, кнопки, поля форм).
- `js/common-plata.js` — рендер сайдбара + мелкие хелперы (money,
  initials, empColor). Это визуальный макет без бэкенда — реальная
  интеграция с API (site-common.js, auth, /api/session и т.д.)
  подключается на следующем этапе, когда дизайн утверждён.
- Каждая страница — отдельный `.html`, использует общие css/js.

## Заметки для следующих шагов
- Общая сетка страницы (`.shell` → `.rail#railRoot` + `.main`) и
  подключение `css/theme-plata.css` + `js/common-plata.js` — уже
  стандарт, дальше просто повторяется на каждой странице.
- В `dashboard.html` сигнатурный элемент — `card-hero` (карточка
  как у Plata: чип, оранжевый градиент, орбитальное кольцо-прогресс).
  Использовать тот же приём для других «денежных» экранов (касса,
  отчёты), но не размножать бездумно — только там, где уместно.
- В `cars.html` добавлен общий набор компонентов формы/модалки в
  `theme-plata.css` (modal, svc-grid, pay-grid, split-grid,
  status-tag, icon-btn) — переиспользуется на `cash.html` и
  `settings.html`, дублировать не нужно, только подключать.
- Модалка и статус-теги в `cars.html` интерактивны косметически
  (JS без бэкенда): открытие/закрытие, чекбоксы услуг, выбор
  оплаты, переключатель раздельной оплаты, клик по статусу —
  это ок для дизайн-макета, реальная логика (расчёт цены,
  валидация, API) подключается на этапе интеграции.
- В `workers.html` — три модалки (график, зарплата с табами
  период/сегодня-неделя-месяц, история дежурств админов),
  переиспользуют `.modal-bg`/`.modal` из `cars.html`, плюс новые
  `.tag`, `table.week`, `.sal-tab`, `.mini-stat` в `theme-plata.css`.
  Все модалки — косметика (открыть/закрыть/переключить таб),
  без реальных расчётов зарплаты.
- В `cash.html` добавлены компоненты `list-row`/`add-row`/
  `inline-split-row`/`close-panel` — общий паттерн «список +
  инлайн-форма добавления», пригодился повторно в `workers.html`
  и `finance.html`.
  Кнопка «Закрыть смену» — `.btn.danger`, сплошной чёрный (не
  красный) — красный в теме зарезервирован под отрицательные
  суммы/ошибки, не под опасные действия.
- В `finance.html` — тот же паттерн `list-row`/`add-row` применён
  к двум колонкам (расходы/доп. доходы), плюс `inline-split-row`
  для раздельной оплаты допдохода. Новых компонентов не
  потребовалось — всё уже было в `theme-plata.css`.
- В `reports.html` (по образцу `carwash045-main/webapp/static/reports.html`)
  — 4 вкладки (Сегодня/Неделя/Месяц/Архив) через новый компонент
  `.tabs`/`.tab` (сегментированный переключатель, активная вкладка —
  оранжевый градиент, как у `.sal-tab.active`); переключение вкладок —
  простой `selectTab()` на голом JS, без бэкенда. Вкладка «Сегодня»
  переиспользует `card-hero` под выручку (как на дашборде) +
  `stat-row` + список топ-услуг на `list-row`. «Неделя»/«Архив» —
  `table.data` с новым модификатором `td.num`/`th.num` (выравнивание
  чисел по правому краю — раньше отсутствовал в теме, добавлен).
  «Месяц» — новый компонент `.month-picker` (выбор месяца/года +
  кнопка, в духе полей `.add-row`). Внизу — блок «Сводка по всем
  филиалам» на новом компоненте `.branch-grid`/`.branch-card`
  (только для роли «владелец» в реальном проекте — в макете показан
  всегда, т.к. ролевой логики в визуальных макетах нет нигде).
  Три новых компонента (`.tabs`, `.month-picker`, `.branch-grid`)
  добавлены в конец `theme-plata.css` — переиспользуемы, если
  где-то ещё понадобятся вкладки/помесячный разрез/сетка карточек.
- В `history.html` (по образцу `carwash045-main/webapp/static/history.html`)
  — лента действий на новом компоненте `.entry`/`.entry-icon`/
  `.entry-body`/`.entry-top`/`.entry-action`/`.entry-time`/
  `.entry-details`/`.entry-actor`, добавленном в `theme-plata.css`.
  Цвет иконки каждой записи берётся из уже существующих токенов
  (`--green`/`--red`/`--purple`/`--orange`/`--accent` + их `-tint`
  пары) — новых цветов не потребовалось, только новая геометрия
  строки. 10 демо-записей покрывают все типы действий из
  `ACTION_META` оригинала (добавление/изменение/удаление машины,
  расход, доход, товар, скидка, ставка, открытие/закрытие смены,
  включая кейс «касса не сошлась» — красная иконка).
- В `branches.html` (по образцу `carwash045-main/webapp/static/branches.html`)
  — новый компонент `.branch-detail`/`.bc-head`/`.bc-detail-name`/
  `.bc-stats`/`.bc-admin-row`/`.bc-admin-select` в `theme-plata.css`.
  **Важно:** название класса карточки — `.branch-detail`, а не
  `.branch-card` — на этой странице карточка другая (крупный
  заголовок + строка статистики + выбор администратора), чем
  маленькая плитка `.branch-card`/`.bc-name`/`.bc-total`/`.bc-meta`
  из сводки на `reports.html`; переиспользование того же имени
  сломало бы одну из двух карточек. Также добавлен `.info-banner`
  (нейтральное уведомление, отличается от `.err-banner`) и
  модификатор `.icon-btn.confirm` (сплошная оранжевая кнопка
  подтверждения — обычный `.icon-btn` в теме обведённый/приглушённый,
  здесь нужен акцентный вариант). Три карточки-филиала: одна с уже
  назначенным админом, одна тоже с админом, одна без — показывает
  оба состояния `.bc-admin-current`.
- В `settings.html` (по образцу `carwash045-main/webapp/static/settings.html`)
  — новые компоненты `.profile-grid`/`.profile-cell` (3-колоночная
  плашка «Мой профиль»), `.user-row2`/`.user-av2`/`.user-info2`
  (строки белого списка сотрудников) и `.logout-panel`/`.lp-title`/
  `.lp-sub` в `theme-plata.css`. Удаление из списка — переиспользован
  уже существующий `.icon-btn.danger` (не понадобился новый
  модификатор). Кнопка «Выйти» — `.btn.danger` (в теме Plata это
  сплошной чёрный, не красный, — та же логика, что и «Закрыть смену»
  на `cash.html`). Добавлен модификатор `.add-row .f-id{width:150px}`
  для поля Telegram ID (у существующего `.add-row` были только
  `.f-name`/`.f-amount`/`.f-pay`, ширины под ID не было).
- `index.html` (страница входа, по образцу
  `carwash045-main/webapp/static/site-login.html`) — последняя
  страница таблицы, редизайн Plata **завершён**. Это единственная
  страница макета, не использующая каркас `.shell`/`.rail#railRoot`
  (входа ещё нет — сайдбар показывать нечего), поэтому весь набор
  классов свёрстан в собственном неймспейсе `.login-*`
  (`.login-page`/`.login-wrap`/`.login-side`/`.login-card`/
  `.login-roles`/`.login-branch-field`/`.login-error` + переиспользуемые
  `.role-btn`/`.btn-submit`), добавленном в конец `theme-plata.css` —
  ничего из существующих компонентов не пересекается по имени.
  Левая панель — сплошная оранжевая заливка `--orange-grad` с
  точечным узором (чистый CSS, без картинок, по мотивам оригинала,
  который делал то же самое на синем сайдбар-градиенте). Клик по
  роли переключает поле «Филиал» (скрыто для «владелец» — тот же
  случай, что и в оригинале). Кнопка «Войти» ведёт на
  `dashboard.html` — косметическая навигация без реального
  бэкенда/авторизации, как и остальные макеты этого раунда.
